# 其他主流观点汇编：工业革命的定义

> 用途：讨论时随时可调取的主流学界、机构、媒体观点。**本文件只罗列他人观点，不对本理论作任何评价或改动。**
> 引用时请注意：以下为公开资料整理，涉及具体数据与年代的表述以原始出处为准。

## 一、学界对"工业革命定义"的学派划分（主流共识）

国外学者对工业革命的研究通常被归纳为以下几派（舒小昀《工业革命定义之争》等文献总结；莫基尔归纳为四个主要派别，后又有能源、消费两个视角的延伸）：

| 学派 | 核心主张 | 判定革命的关键标志 |
|------|---------|------------------|
| **社会变革学派** | 工业革命是包括政治、经济、社会、文化在内的全面巨大变革；实质是"人与人之间经济交易方式的大变革"——竞争性市场取代中世纪控制财富生产和销售的行规 | 市场制度与交易方式的变革 |
| **工业组织学派** | 关注工厂制度的兴起及其组织劳动的纪律；强调资本形式的更迭——从流动资本（种子、原材料）转向固定资本（机器、矿山、建筑） | 生产组织形式（工厂制）的确立 |
| **宏观经济学派** | 关注国民收入、资本形成率、总投资比率、劳动力增长与构成等宏观经济指标的变化；代表研究有刘易斯从生产性投资率、制造业和制度结构层面考察 | 投资率等宏观指标的突变 |
| **技术学派** | 突破性科技的出现和连续不断的技术变革是根本特征；兰德斯用"被解放了的普罗米修斯"形容——机械设备替代人的劳动、无机能源（蒸汽）取代人畜力、冶金与化学工业改进 | 标志性技术的广泛应用 |
| **能源学派** | 工业革命根本上改变了人们获取能源的方式，满足以能量需求为核心的物质需求；新能源的利用或能源获取及使用方式的变化是核心指标 | 能源获取方式的改变 |
| **消费学派** | 日益扩大的供求缺口即消费需求的产生推动了工业革命的发生；消费是一切生产的目的 | 消费需求端的扩张 |

**趋向综合性定义**：研究越来越趋向于把各学派核心要素综合起来，构成一个评价或定义的集合体系。

## 二、一个"综合版"的四条件判定（李尧远，《三联生活周刊》文章）

判断一场变革是不是工业革命，大概需要四个条件，**只有同时具备**才能称为工业革命：

1. 能够深刻影响生产生活尤其是生产组织形式变化的非传统核心技术体系革新；
2. 生产效率的提升和经济社会的快速持续发展；
3. 政治、经济、社会、文化等领域的系统性变革；
4. 新能源的出现或能源利用方式的变化。

> 文中强调：其中一个或两个领域的变化不能以"工业革命"相称——这正是**科技革命的次数多于工业革命次数**的原因。

## 三、经济史学界关于"为什么是英国"的主流解释

| 学者 / 著作 | 核心观点 |
|------------|---------|
| **罗伯特·艾伦**（Robert C. Allen，《近代英国工业革命揭秘》） | 英国率先发生工业革命的原因在于**高工资 + 廉价的煤炭能源**：1750 年英国劳动力价格约为法国、意大利的 1.7 倍，用机器替代人工变得有利可图，同时煤炭价格低廉，蒸汽机、机械棉纺设备、焦炭冶铁技术才最先在英国登场。他认为"工业革命"很难称为一个"突发事件"，更接近近一个世纪的过程。 |
| **乔尔·莫基尔**（Joel Mokyr，《启蒙经济》The Enlightened Economy） | 强调**"工业启蒙"**：精神世界与精英文化的变化、科学革命带来的实验文化，使少数受过良好教育的"宏观发明"者把科学与生产连接起来。艾伦则反驳说，工业启蒙主要是上层文化现象，与生产关系不大。 |
| **彭慕兰**（Kenneth Pomeranz，《大分流》） | 加州学派代表：英格兰相对亚洲部分地区的工业优势约到 1800 年前后才显现；强调**煤炭资源与殖民地财富**（全球化攫取）的作用，而非单纯的制度或文化差异。 |
| **文一**（《伟大的中国工业革命》） | **"胚胎发育理论"**：工业是复杂有机体，工业革命按顺序展开，每一阶段都需要前一阶段的"原始"积累来创造市场、获得融资。核心论断——**技术发明不能自动创造对它自身的需求**（批评"萨伊定律"谬误），是"需求创造供给"；大规模市场是成本极其高昂的公共品，必须由有为政府提供；因此中国 1978 年后的乡镇企业繁荣＝原始工业化阶段，才引爆第一次工业革命。 |
| **能源视角学者**（瓦茨拉夫·斯米尔、E. A. 里格利、W. F. 科特雷尔等） | 把能量（焦耳）投入视为经济活动的根本约束，能源来源的替代与转换是理解工业革命的钥匙；相关综述认为英国工业革命"首先是一场能源革命"。 |

## 四、关于"新工业革命"的官方/机构定义（中国视角）

中国科学院科技战略咨询研究院课题组的定义被广泛引用：

> **新工业革命是以数字化、网络化和智能化为主要特征，并以新一代信息技术为核心。** 云计算、大数据、移动互联网、物联网、人工智能、区块链等新兴技术深度融合到各个产业中，推动技术集群式突破和融合；生物医药、新能源、新材料成为重要支撑方向，共同构成**"一主两翼"**的发展格局。

这一定义与德国"工业 4.0"、世界经济论坛"第四次工业革命"的口径基本一致，属于**信息/智能技术主导**的定义。

## 五、对比速查表

| 维度 | 主流观点 | 本理论观点 |
|------|---------|-----------|
| 定义方式 | 多学派并列、趋于综合（把各要素凑成集合体系） | 单一明确定义：工业过程/规模/技术等相关领域的突变式社会产业变革 |
| 判定标准 | 四条件（技术体系革新、效率与持续发展、系统性社会变革、新能源或能源利用方式变化） | 五特征（社会影响规模、市场经济价值、技术理论进步、生产力发展、历史因果关联），且须**同时**具备 |
| 对"革命"的理解 | 可长时段、渐进（艾伦：近一个世纪的过程，难称"突发"事件） | 明确要求**爆炸式增长、突变式发展**，反对渐进累加式算作革命 |
| 革命起点 | 制度/市场/技术/能源多因并陈 | 明确指向**能源和动力**这一"基础硬件" |
| "新工业革命"指什么 | 数字化、网络化、智能化（信息/智能技术主导） | 能源、动力、排放三大理念主导的技术创新 |

# 其他主流观点汇编：被质疑的"第三次/第四次工业革命"概念

> 用途：讨论时随时可调取。**只罗列他人观点（含支持方与批评方），不对本理论作评价或改动。**

## 一、被讨论的对象：这些概念本身说了什么

### 1. 里夫金《第三次工业革命》（2011/2012）

- **核心命题**：工业革命必须包含三要素——**新能源技术的出现、新通讯技术的出现、以及新能源与新通讯技术的融合**；第三次工业革命＝**互联网技术与可再生能源的融合**，带来生产与生活方式的再次巨大改变。
- **五大支柱**：① 向可再生能源转型；② 把建筑转化为就地收集能源的微型发电厂；③ 在建筑与基础设施中使用氢和其他存储技术储存间歇式能源；④ 利用互联网技术把微电网连成"能源互联网"；⑤ 插电式与燃料电池交通工具从互动电网取电。
- **治理模式差异**：前两次是"垂直模式"，能源互联网是"自下而上（bottom up）"的分散模式。

### 2. 施瓦布 / 德国"工业 4.0"

- **起源**："Industrie 4.0"于 2011 年汉诺威工业博览会首次提出，后作为德国政府《高技术战略 2020》十大未来项目之一；施瓦布 2015/2017 年著作使"第四次工业革命"一词广为流传。
- **施瓦布的三点论据**：**速度**（指数级而非线性）、**广度与深度**（数字经济与多种技术结合带来前所未有的转变）、**系统性影响**（跨国家、企业、行业、社会的整个系统变革）。
- **特征**：智能制造/智能工厂、物联网、机器人与机器学习替代劳动（并可能自动化部分知识工作）、纳米技术、3D 打印、生物技术、量子计算、可再生能源与储能。

## 二、批评方观点（可直接引用）

| 来源 | 主要论点 |
|------|---------|
| **庞名立《千万不要被"第三次工业革命"忽悠了！》**（本理论文献亦引用） | "再生能源+互联网=零成本"很能忽悠；再生能源并非零成本，光伏是目前最贵的电力之一（2013 年全球光伏发电仅占发电总量 0.54%，德国 4.73%）；屋顶光伏与家用风机无法支撑不断增长的电力需求（2003—2013 全球发电量增 37.8%，人口仅增 12.0%）；批评书中"核能从来不是清洁能源"的说法，主张**清洁能源＝再生能源+核能**；直言"数以亿计的人在自己家里生产绿色能源……实属空谈"。 |
| **中国青年报《"第三次工业革命"忽悠谁》（2012-07-23）** | 把互联网与新能源两个概念嫁接在一起再次预言"革命"；太阳能、风能、水电、生物能本质上仍是**"采集能源"而非"制造能源"**，与煤、石油属同一技术级别；真正革命式的深度开发是**从核裂变到核聚变**——从采集化石资源到"生产能源"；3D 打印机"其实就是快速成型机，只是一台变种的机床"；真正的革命只会发生在信息技术、生物技术、太空技术、新能源等前沿科技的**交叉领域的系统性创新**。 |
| **《给"第三次工业革命"泼泼冷水》**（中国能源网） | 工业革命的重要标准是**生产方式发生了能被大范围推广的颠覆性革新**；信息技术与能源技术是导火线，但如果没有引起生产方式的有效突破，只能算**科技革命或能源革命**，算不上工业革命；分布式技术目前只是批量生产方式的补充（模块化生产、下包制只是改良，甚至只是商业模式变化）；**动力强度和控制精度的技术性突破一日不实现，工业革命就一日难以起步**。 |
| **工控网评论文章** | "第三次工业革命"是概念炒作，三大支撑论据都"忽悠成分大于实质"：3D 打印是增材制造，制成品材料强度问题难以克服，优势只在复杂物品成型；自动化并不真正节约人力，只是改变人力用途；能源革命的最大论据页岩气长期亏损（盈亏平衡点约 7 美元/百万英热，实际气价 3~4 美元），"是个泡沫的可能性远大于是一场革命"。 |
| **《It's Not the Fourth Industrial Revolution!》（Corinium Intelligence）** | 这个标签是"扩张主义的""误导且无益的"；指出这至少是**第六次被称作"第四次工业革命"**（前五次分别是 1948 年原子能、1955 年泛在电子、1970 年计算机、1984 年信息时代、以及纳米技术）；若真要分期，更合理的是四波变革技术：1712 年原始蒸汽机与纺织机械、1830 年移动蒸汽机与铁路、1875 年钢铁与重工程及化工、1910 年石油电力与大规模生产；作者认为物联网与智能制造**属于"信息革命"的一部分**，而不是工业革命的又一轮。 |
| **英国下议院图书馆辩论简报（CDP-2016-0153）** | 直言"第四次工业革命"是一个**定义模糊的术语（a vaguely defined term）**，用来指称 21 世纪以来各种技术变革与创新。 |
| **学术论文《Repudiating the Fourth Industrial Revolution Discourse》** | 认为 4IR 话语是**技术决定论式的新自由主义纲领延续**：技术归私人资本所有，应对紧迫社会挑战的能力被置于附属位置；把管理技术发展的责任交给企业，掩盖了"变革的观念是负载价值的"这一事实；呼吁让未来话语向多元声音开放。 |
| **Asadollahi-Yazdi 等（2020）** | "第四次工业革命"缺乏足够的时间纵深来宣示，这一"革命"**只是通过若干技术发展而成型的一次演进（evolution）**。 |
| **文一（上海交大）专访，2023-06-19** | **ChatGPT 的出现不是一场独立的工业革命**，它仍是信息技术革命"替代脑力"的一环，只是在第三次工业革命中具有里程碑意义；判断革命要看动力、能源、通讯与交通方式是否发生巨大变革，以及是否由巨大的全球统一大市场与需求推动。 |

## 三、支持方 / 中间派观点（讨论时的另一面）

| 来源 | 主要论点 |
|------|---------|
| **国内对"第三次工业革命"的三种态度**（天津市国资委网站整理） | ① 认为只是互联网+新能源的概念嫁接，是忽悠；② 认为还难说新革命已经开始，但以"信息和远程通信"为标志的第五次技术革命浪潮、以"纳米技术、新材料、新能源和生物电子"为标志的第六次技术革命浪潮值得重视；③ 认为第三次工业革命已初露曙光，中国不能再错过。 |
| **《"第三次工业革命"来袭》（同上）** | 引用欧盟目标：2020 年前可再生绿色能源提供 20% 电力，2030 年达 30%；德国计划 2020 年可再生能源占能源总需求 35%；建筑业领袖认为该模式在设计与建筑业"奏响了最强音"。 |
| **《智能化来袭 中国企业要关注变革先机》（中国工业新闻网）** | 对"忽悠论"不以为然：综观世界工业近 50 年发展历程，很多趋势性研究并不只是忽悠，**反倒是不重视"忽悠"的国家吃了大亏**；认为第三次工业革命的判断更能让人接受。 |
| **光明日报《新自由主义的"滑铁卢"》（2012-11-17）** | 肯定里夫金从能源切入点长期研究经济活动中能量消耗与市场体系的关系，指出"生产本身所消耗的能量要比产出的产品和服务大得多"，认为其从技术革命角度阐明未来经济形式值得推荐。 |

## 四、对比速查表

| 概念 | 主流看法（主流/官方口径） | 本理论看法 |
|------|------------------------|-----------|
| 第三次工业革命（里夫金） | 通信技术与可再生能源融合，五大支柱，自下而上的能源互联网 | 不符合五特征；属于"热炒剩饭"式的再包装 |
| 第四次工业革命（施瓦布/工业 4.0） | 速度、广度深度、系统性影响；智能制造与物联网 | 不符合五特征；智能制造不等于产业革命 |
| 3D 打印 | 数字化制造代表；批评者认为是快速成型机、材料强度受限 | 是返回手工作坊式的个性化定制，不是革命 |
| 电动汽车 | 新能源汽车主流路线；批评者认为是百年前"电池+电动机"的翻新 | 不是市场需求驱动，是环境政治任务；不算创新 |
| 互联网/大数据/云计算 | 数字经济核心；有批评认为只是通信技术先进形态 | 属于"应用软件"，不是"基础硬件" |
| 页岩气 | 曾被视作能源革命论据；批评者指其长期亏损、是泡沫 | （本理论文献未专门论述，可参照"伪概念"判定标准讨论） |

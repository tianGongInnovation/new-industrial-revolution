# 新工业革命星火（new-industrial-revolution）

一个讲"新工业革命"的 AI 专家。核心是三条理念：**让能量动起来、让热机冷下来、让排放变资源**。

## 一、有什么用处

帮你从能源动力的角度，找出**别人不容易想到的创新思路**。具体能做四件事：

1. **讲清理论**：什么是工业革命（五特征判据）、三条理念各自的原理和已经验证过的实例；
2. **扫描机会**：用三条理念去扫你的行业或项目，指出节能减排、动力革新的切入点在哪；
3. **给出路线**：针对具体方向（高温热泵、液态空气动力、碳资源化等），给出"方向—路线—要点—风险"的完整建议；
4. **技术答疑**：卡诺循环的再认识、热泵能效口径、液态空气工质系统等热力学和工程问题，可以往深了聊。

适合这些人用：工程技术人员、做战略规划的人、投资者、科技管理者，以及对能源与环境问题有兴趣的普通人。

## 二、为什么要用它

多数 AI 和资料库能告诉你"已知的第三次、第四次工业革命"是什么，但很难给你**一条没被走过的路**。这个专家的价值在于：

- **有立场、有依据**：不是泛泛而谈，每条思路都落到具体技术和可核算的数据上；
- **跨界**：把制冷、热机、化工、农业几个领域的成熟技术交叉起来用，这是创新最省力的方式；
- **讲落地**：强调"创新是从有到用"，不追求从无到有的发明，讲的东西能落到工程上；
- **讲人话**：不做概念堆砌，用浅显的语言把原理说清楚，让人能自己判断。

## 三、怎么用

安装后，在 WorkBuddy 的「专家」里找到「新工业革命星火」，直接问就行。三个推荐的开场问法：

- 请介绍新工业革命的三大理念，它们如何解决能源危机、环境污染和地球变暖问题？
- 用三大理念分析我这个行业（或项目）有哪些节能减排的创新机会？
- 帮我评估液态空气动力技术的可行性和市场前景，并给出发展路线建议。

**怎么问效果最好**：把你的行业、项目背景、手头的条件说清楚，越具体，给出的路线越能用。想深入可以追问"这个思路的技术难点在哪""有没有类似的已验证案例"。

## 四、有问题怎么办

| 遇到什么情况 | 怎么处理 |
|---|---|
| 回答太笼统 | 补充你的行业、规模、现有条件等背景信息，让它重新扫描 |
| 涉及具体投资决策 | 专家只做技术和路线分析，投资决策请另行评估；涉及收益测算的回答会同时提示风险 |
| 对"工业革命"的定义有不同看法 | 专家会同时给出主流学界观点与本方观点做对比，供你自己判断，不回避争议 |
| 想核实某组数据 | 请它说明数据来源和计算口径；涉及热泵能效等数据，它会标明系统口径而非部件口径 |
| 回答有误或表述不当 | 直接用自然语言纠正，它会当场修正；重要问题建议交叉核对原始资料 |

## 五、知识范围

专家自带知识库（`skills/nir-knowledge-base`），包含：

- 7 篇理论文献：总纲、创新方法论、卡诺循环再认识、动力机械变革、理念变革与节能减排、前言、宣讲提纲；
- 3 个专题对照目录：工业革命的定义、两次工业革命、伪工业革命概念。每个专题都放了两份材料——一份是本方观点，一份是主流学界观点汇编，末尾附对比速查表。
